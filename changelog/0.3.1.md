## Fixed

- QuickAdd input prompts, such as the task title in "TaskNotes - Create task for project", no longer reopen pre-filled with text from the previous run. This turns off QuickAdd's "Persist Input Prompt Drafts" setting. Syncing QuickAdd `data.json` (`--data-json`) is needed to apply this to existing vaults, or turn the setting off manually

## Changed

- QuickAdd macros "TaskNotes - Create task for project" and "TaskNotes - Set current note as project" are no longer registered as command palette commands (`command: false`). Run them from the QuickAdd menu, or turn the lightning-bolt toggle back on in QuickAdd settings. Syncing `data.json` (`--data-json`) is needed to apply this to existing vaults
