# [0.1.0] - 2026-10-18

First tagged release of the template. It summarizes the vault as it stands today.

## Added

- Opinionated vault in `template/`: folder structure with a folder note per folder, Templater frontmatter templates for notes and reference notes, and a knowledge-confidence-level property and base.
- Curated plugin set (Dataview, QuickAdd, TaskNotes, Templater, Excalidraw, ExcaliBrain, Advanced Canvas, Folder Notes, Linter, Omnisearch, Vertical Tabs and more), loaded through Lazy Loader.
- TaskNotes task management with pre-built base views and a priority/status system.
- QuickAdd scripts to create a task in the current folder, create or open a default tasks view and a notes base for a folder, create child notes, and wrap a file in a folder of the same name. Shared helpers keep the scripts consistent.
- Claude Code skills for Obsidian (markdown, bases, CLI, canvas, QuickAdd, defuddle), kept in `.agents/skills` and symlinked from `.claude/skills`.
- Repository workflow skills: `git-workflow-and-versioning` (generic) and `obsidian-template-git-workflow` (commit, changelog and release rules for this repo).
- `mise run sync` copies plugins, content directories and Obsidian settings from the template into other vaults. The wizard now compares the template with the selected vaults first, lists what already matches, and labels every option as in sync, outdated, partial or not synced. After copying it checks that the synced items match.
- `mise run compare [vault]` reports which plugins, directories and settings of a vault match the template (`--verbose` lists files, `--json` for scripts, `--check` exits non-zero when anything differs).
- `state.json` describes the template: its plugins, which directories and Obsidian settings can be synced, and which are left out. `mise run state` refreshes it from `template/` (`--check` only verifies), and releases refuse to go out when it is stale.
- `mise run release <patch|minor|major>` rolls the changelog, bumps the version and tags the release.

## Changed

- QuickAdd folder scripts were renamed from `create*` to `createOrOpen*`. Update any hotkeys or macros that reference the old names.
- Notes created through QuickAdd now include the template body, not just the frontmatter.
- Creating a task for a project now creates the project note if it is missing.

## Removed

- The `npm run sync` script. Use `mise run sync` instead.

## Fixed

- The ExcaliBrain directory is synced under its real name (`ExcaliBrain`), so selecting the ExcaliBrain plugin also copies it on case-sensitive file systems.
- The folder base no longer errors on notes without a `Parent` property, and its Notes filter now follows `Parent` instead of the folder location.
- Linking a task to a project no longer produces an ambiguous wikilink.
